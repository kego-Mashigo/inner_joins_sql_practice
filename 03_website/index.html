What is an INNER JOIN?

Let's understand the concept step by step.

1

The Basic Idea

An INNER JOIN is used to combine rows from two or more tables based on a related column.

The important thing to remember is:

INNER JOIN returns only the records that have matching values in both tables.

Think of it as finding the data that exists in both tables.

What happens when we INNER JOIN?

The database looks for customer IDs that exist in both tables.

Customer IDs 1 and 2 exist in both tables.

Customer IDs 3 and 4 don't have matching orders, while customer ID 5 doesn't exist in the Customers table.

Write the INNER JOIN

Now let's translate the idea into SQL. 

SELECT
    customers.customer_id,
    customers.customer_name,
    orders.order_id

FROM customers

INNER JOIN orders
    ON customers.customer_id = orders.customer_id;
SELECT

Specifies which columns you want to see in the final result.

INNER JOIN

Combines rows from the two tables.

ON

Defines the condition used to match the tables.
